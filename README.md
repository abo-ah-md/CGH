## Overview

**Rahalh** is a web-based travel solution developed as part of the SaudiChatGPT Hackathon. The project aims to integrate intelligent APIs and provide seamless experiences for users planning and managing travel. Developed by a team from TUWAIQ Academy, Rahalh leverages technologies like Elm and vectara, and showcases innovation in smart travel services.

## Features

- **Smart API integrations** (e.g., vectara, Elm)
- User-friendly travel planning and management
- Modern frontend and backend stack
- Complete business plan: [Read Rahalh.pdf](./Rahala.pdf)

## Project Structure

- `src/` — Main source code
- `test/` — Test suites
- `Rahala.pdf` — Business plan (project presentation)
- Config files: `.babelrc`, `.gitignore`, `package.json`, `webpack.*.js`
- Additional resources and documentation

## Technologies Used

- **HTML, JavaScript, SCSS**
- **Elm API, vectara API**
- **Geonames, WeatherBit, Pixabay** (external services)
